## 为什么要看这个网站

网上的美股资料不少，但要么是英文写给美国人看的，要么是中文写得像教材——上来就是「量化宽松货币政策」「波动率曲面微笑」，让人三秒关掉页面。

这个网站的出发点很简单：**用你跟朋友聊天的语气，把同样的知识讲清楚**。不需要任何金融背景，从「股票是什么」一路读到「我该怎么卖一个铁鹰期权」。

每一章结构固定：先用一个真实故事把你带进去，再讲核心概念，配数字例子，最后点出新手最容易踩的坑。读完有术语表，有小测验，随时回来复习都方便。

## 8 个可以动手玩的互动工具

光读文字记不住，每章配了一个工具让你自己调参数、看结果：

- **复利计算器** — 输入本金、年化收益、年限，直观看时间的复利效应
- **PE/PB 估值对比器** — AAPL / MSFT / JPM / TSLA 雷达图，体会为什么跨行业比 P/E 毫无意义
- **财报三表资金流向动画** — 点击看钱是怎么从营收一路流到自由现金流的
- **K 线形态图鉴** — 12 种经典形态，悬浮即显解释和「看涨 / 看跌 / 中性」判断
- **板块轮动时钟** — 拖动经济周期指针，看哪个阶段哪些板块历史上更强
- **期权 Payoff 图** — 滑块调行权价和到期日，实时画出备兑 / 价差 / 铁鹰 / 跨式的损益曲线
- **希腊字母模拟器** — 调股价、波动率、到期日，实时看四个希腊字母怎么联动变化
- **仓位计算器** — 输入胜率和盈亏比，算出 Kelly 公式建议的单笔仓位
